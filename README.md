# Eikon.ai

Eikon é uma plataforma web voltada para experiências conversacionais com personagens IA, combinando frontend moderno, backend modular e integração com serviços de inteligência artificial. O projeto foi desenvolvido para demonstrar maturidade em produto digital, experiência de usuário, arquitetura de software e operação em ambientes reais.

## O que o projeto entrega

- interface web com foco em conversação e interação com personagens;
- fluxo de autenticação e perfil de usuário;
- navegação por descoberta, busca e engajamento;
- backend estruturado para autenticação, dados, IA, social e operações mais robustas;
- base preparada para evolução em produto, escalabilidade e integração com novas funcionalidades.

## Stack principal

- Next.js e React para a camada de interface;
- TypeScript para organização e segurança de código;
- Node.js e Express para a API backend;
- PostgreSQL, Redis e Supabase para persistência e cache;
- integração com APIs de IA e serviços externos.

## Arquitetura

O projeto está organizado em duas camadas principais:

- frontend: experiência visual, navegação, componentes e integração com a API;
- backend: regras de negócio, autenticação, chat, social, armazenamento e segurança.

Essa separação reforça a clareza do projeto e a capacidade de evolução independente entre produto e infraestrutura.

## Como executar

### Frontend

```bash
cd eikon/frontend
npm install
npm run dev
```

### Backend

```bash
cd chatback/backend
npm install
npm run dev
```
