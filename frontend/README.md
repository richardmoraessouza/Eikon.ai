# Eikon.ai — Frontend

Eikon é uma plataforma web de conversação com personagens IA, voltada para experiências imersivas de interação entre usuário, personagens fictícios e personas personalizadas. O projeto combina UX, arquitetura modular de frontend, autenticação, integrações com APIs externas e um produto com forte identidade visual e funcional.

## Visão do produto

A plataforma foi pensada como um ambiente onde o usuário pode:

- conversar com personagens alimentados por IA;
- criar e gerenciar perfis personalizados;
- explorar personagens, conteúdos e comunidades;
- interagir com recursos de descoberta, social e engajamento.

Para recrutadores, isso representa um projeto que vai além de uma interface estática: é uma aplicação com foco em produto, usabilidade, estrutura escalável e integração com backend e serviços externos.

## Principais funcionalidades

- autenticação com Google e fluxo de usuário;
- interface de chat com personagens;
- perfis de usuário e personalização;
- navegação por descoberta, busca e exploração;
- sistema social com interação entre usuários;
- experiência de uso com menus, contextos e hooks organizados.

## Stack técnica

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Axios e cookies para comunicação e sessão
- Supabase para armazenamento e integração de dados
- OAuth Google
- React Markdown para renderização de conteúdo

## Arquitetura e qualidade de código

O frontend foi organizado com uma estrutura modular, separando:

- componentes reutilizáveis;
- hooks para lógica específica;
- contextos para estados globais;
- serviços para comunicação com APIs;
- páginas com organização por rotas e layouts.

Esse desenho demonstra boa capacidade de evoluir o projeto de forma organizada, mantendo clareza entre UI, estado e integração.

## Como rodar localmente

1. Entre na pasta do frontend:

```bash
cd eikon/frontend
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

4. Acesse:

```text
http://localhost:3000
```
